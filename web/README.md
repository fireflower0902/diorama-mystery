# 4°C — 웹 추리 게임 (프로토타입)

## 실행
- `index.html`을 브라우저로 바로 열면 된다. 서버나 설치가 필요 없다.
- 진행 상황은 브라우저에 자동 저장된다. 처음부터 하려면 게임 메뉴(⋯) → "처음부터 다시".
- 개발 중 빠른 초기화: 주소 끝에 `#reset`을 붙여 새로고침.

## 구조
| 파일 | 역할 |
|---|---|
| `js/data.js` | 사건 규칙: 증거 목록, 연결(추론) 쌍, 최종 질문, 엔딩, 단계별 힌트 |
| `js/content.js` | 화면 콘텐츠: 메시지, 메일, 클라우드, 메모, 워치 기록, 출입·주차 기록, CCTV 프레임, 형사 통화 |
| `js/scenes.js` | SVG 그림: CCTV 장면, 신발 확대, 홈커밍 사진, 지도, 워치 그래프, 도면 |
| `js/audio.js` | 사운드: Web Audio로 합성한 효과음·배경음, 브라우저 음성 합성(TTS). 음원 파일 없음 |
| `js/characters.js` | 피규어(넨도로이드풍) 임시 캐릭터 7명. 표정 교체 `CHARS.setExpression` |
| `js/world.js` | 3D 공간: 방 3개(5층 연구실·1층 로비/경비실·지하 복도), 캐릭터 이동, 사물 클릭, 엘리베이터 이동 |
| `vendor/three.min.js` | Three.js r149 (MIT). 오프라인 실행을 위해 포함 |
| `js/app.js` | 엔진: 상태 저장, 화면 전환, 증거 수집, 연결 판정, 힌트, 엔딩 판정, 점수 |
| `css/style.css` | 스타일 (기기별 프레임: 휴대폰·노트북·CCTV·문서) |

새 사건은 `data.js`와 `content.js`만 바꾸면 된다(엔진은 공통). 스토리 설계는 [../아이디어/스토리초안_4도.md](../아이디어/스토리초안_4도.md) 참고.

## 핵심 규칙
- 콘텐츠 항목에 `ev: '증거ID'`가 있으면, 그 항목을 열 때 증거가 수사 보드에 들어간다.
- `insights`의 `pair` 두 증거를 수사 보드에서 연결하면 사실이 드러난다. `requires`가 있으면 앞의 사실이 먼저 필요하다.
- 진행 잠금: 노트북(암호) → CCTV·기록(형사 통화에서 `i_phone` 근거 제시).
- 엔딩: 위치 오답 → 한강 / 범인 오답 → 엉뚱한 사람 / 동기 오답 → 반쪽짜리 진실 / 전부 정답 → 4°C.

## 사운드
- **효과음:** 증거 획득, 사실 발견, 잘못된 연결, 잠금 해제·실패, 알림, CCTV 잡음, 확대, 전화 연결음·통화 중·종료, 힌트, 엔딩
- **배경음:** 인트로 / 수사 중 / CCTV(전원 험 + 잡음) / 진 엔딩(밝은 화음) / 배드 엔딩(낮은 단조)이 화면에 따라 자연스럽게 바뀐다
- **음성:** 인트로·엔딩 내레이션, 형사 통화 대사(목소리 높낮이로 인물 구분). 한국어 음성은 OS에 따라 다르다
- 오른쪽 위 🔊 버튼으로 전체 켜기/끄기, ⋯ 메뉴에서 배경음·효과음·음성을 따로 끌 수 있다. 설정은 저장된다
- 브라우저 정책상 첫 클릭 전에는 소리가 나지 않는다. 그래서 시작 화면에 "사건 파일 열기" 버튼을 둔다

## 3D 공간
- 바닥 클릭 또는 WASD/방향키로 걷는다. 사물을 클릭하면 캐릭터가 다가가서 조사한다. ◆는 아직 안 본 곳.
- 사물 → 화면 연결
  - 5층 연구실: 서윤의 노트북(노트북 화면), 책상 서랍(열리면서 연구 노트), 사진 액자, 화이트보드, 실험대, 강태오(대화), 엘리베이터
  - 1층: CCTV 모니터·관제 단말(형사 통화 후 열림), 경비원(대화), 정문, 후문
  - 지하 1층(형사 통화 후 엘리베이터로 이동 가능): 저온 시료보관실 문(사실이 드러나면 최종 추론으로), 기계실, 주차장 연결문
- 내 휴대폰, 수사 보드, 최종 추론은 오른쪽 아래 버튼으로 언제든 연다.
- 방과 사물 배치는 `world.js`의 `ROOMS`, 조사 문구는 `content.js`의 `examine`에 있다.

## 캐릭터·배경 교체 계획 (나중에)
- 지금 캐릭터는 코드로 만든 **임시 피규어**다. 다른 AI나 외주로 그림이 준비되면 교체한다.
- 교체 방식 후보: ① 2D 일러스트를 아크릴 스탠드처럼 세우기 ② glTF(.glb) 3D 모델 불러오기
- 교체 지점은 `world.js`의 `figure(id)` 한 곳이다. 같은 id(`seojin`, `taeo`, `guard` 등)로 새 모델을 돌려주면 이동·표정 연출은 그대로 쓴다.
- 그림 파일은 `web/art/characters/인물_표정.png`, 배경 참고는 `web/art/reference/`에 둔다.

## 사건 추가 구조 (2편부터)
- 사건마다 `cases/<id>/data.js`(규칙·엔딩·힌트·타임라인·인물·패널 구성)와 `content.js`(메시지·영상·기록·조사 문구)를 둔다.
- `js/cases.js`의 `CASE_LIST`에 등록하면 시작 화면 "사건 선택"에 나타난다. 3D 공간은 `world.js`의 `ROOMS`에 추가한다.
- 현재 사건: `four`(4°C), `room`(모찌는 어디에)

## 음성 (Edge TTS 녹음 파일)
- 대사를 고치거나 추가했다면: `pip install edge-tts` 후 `node tools/make_voices.mjs <edge-tts 경로>` 실행 → 바뀐 줄만 `audio/voice/`에 새로 만든다.
- 녹음이 없는 대사는 브라우저 합성 음성으로 읽는다. 정식 출시 때는 유료 음성(ElevenLabs·타입캐스트 등)으로 파일만 교체한다.

## PC + 모바일 가로
- 모든 화면은 PC와 휴대폰 가로 모드 둘 다 지원한다 (`css/style.css`의 `max-height: 520px` 가로 규칙).
- 휴대폰 테스트: 같은 와이파이에서 `python3 -m http.server 8791 --bind 0.0.0.0` 실행 후 휴대폰에서 `http://<맥 IP>:8791` 접속.
