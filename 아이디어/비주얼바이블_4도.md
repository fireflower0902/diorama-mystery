# 비주얼 바이블 + 「4°C」 설정집

> 게임 전체의 그림 규칙(1부)과 에피소드 「4°C」의 캐릭터·공간 설정(2부), AI 이미지 생성용 프롬프트(3부).
> 3D 모델을 만들 때, 그림을 외주할 때, AI로 컨셉을 뽑을 때 모두 이 문서를 기준으로 삼는다.

---

# 1부. 비주얼 바이블 (모든 에피소드 공통)

## 1-1. 한 줄 컨셉: "상자 속의 사건"
사건 하나가 **나무 받침대 위의 모형 세트**로 놓여 있고, 플레이어는 그 모형 속을 들여다보며 수사한다.
겉모습은 아기자기한 미니어처, 안에 담긴 이야기는 무겁다. **이 대비**가 게임의 정체성이다.

## 1-2. 고정 규칙 (에피소드가 바뀌어도 그대로)

| 항목 | 규칙 |
|---|---|
| 시점 | 위에서 비스듬히 내려다보는 디오라마 시점. 앞쪽 벽은 잘라 내부가 보이게 한다 |
| 받침대 | 모든 공간은 두께 있는 나무 받침대 위에 놓인다. 받침대 앞면에 사건명·장소명 명판 |
| 캐릭터 비율 | **2.5등신.** 머리가 키의 약 40%. 손은 동그란 벙어리장갑형, 손가락 없음 |
| 얼굴 | 눈은 세로로 긴 타원 점 두 개. 코 없음. 입은 평소엔 없고 감정 장면에서만 표시. 볼터치는 연하게 |
| 형태 | 모서리는 모두 둥글게(베벨). 덩어리는 단순하게. 실루엣만으로 누군지 알 수 있게 |
| 재질 | **무광 점토/레진 피규어 느낌.** 반사 없음, 부드러운 확산광. 금속·유리만 살짝 광택 |
| 색 비율 | 60(배경 기본색) : 30(보조색) : 10(포인트색). 포인트색은 단서와 감정 장면에만 |
| 단서 강조 | 조사 가능한 사물은 에피소드 포인트색의 부드러운 외곽 빛 + 위에 ◆ 표시 |
| 화면 효과 | 위아래 흐림(틸트시프트)으로 미니어처 느낌. 약한 비네팅. 필름 그레인은 에피소드 선택 |
| 글자 | 공간 속 표지판·화이트보드 글씨는 실제로 읽을 수 있게(단서가 될 수 있음) |

## 1-3. 에피소드마다 바꾸는 값 (테마 프리셋)

에피소드 데이터에 아래 값만 넣으면 같은 모델로도 분위기가 바뀐다.

| 값 | 설명 | 「4°C」 예시 |
|---|---|---|
| `base` | 배경 기본색 (60%) | 회청 `#C9D3DA` |
| `sub` | 보조색 (30%) | 차가운 회색 `#8E9AA6`, 나무색 `#C9A27E` |
| `accent` | 포인트색 (10%) | 살구 `#F2A07B` (서윤의 온기), 경고 빨강 `#E5534B` |
| `light` | 주광 색온도·세기 | 흐린 오후 6500K, 약하게 |
| `weather` | 날씨 | 비 (창밖 빗줄기, 창에 물방울) |
| `time` | 시간대 | 일요일 오후 3시 → 엔딩 오후 5시 |
| `post` | 화면 효과 | 틸트시프트 중간, 채도 -15%, 푸른 그림자 |
| `outfit` | 인물 의상 세트 | 늦가을 (코트, 니트, 패딩) |

## 1-4. 캐릭터 제작 원칙
- **기본 몸체 하나**를 모든 인물이 공유한다. 머리 모양, 옷, 소품, 색만 바꿔 끼운다.
- 인물마다 **대표색 1개 + 시그니처 소품 1개**를 둔다. 멀리서도 구분된다.
- **단서가 되는 외형**(예: 신발)은 일부러 크고 분명하게 만든다. 플레이어가 놓치면 추리가 성립하지 않는다.
- 감정 표현은 얼굴 대신 **자세와 소품**으로: 어깨 처짐, 손에 쥔 휴대폰, 고개 숙임.

# 2부. 「4°C」 설정집

## 2-1. 에피소드 무드
- **키워드:** 차가움, 비, 형광등, 기다림, 숨겨진 온기
- **색 이야기:** 공간 전체가 회청색으로 식어 있다. **서윤과 관련된 것만 따뜻한 살구색**(서윤의 책상 소품, 액자, 연구 노트). 진실에 가까워질수록 지하의 푸른 냉기가 강해진다.
- **조명 흐름:** 5층(흐린 자연광) → 1층(창백한 형광등) → 지하(푸른 저온실 빛 + 깜빡이는 형광등)

# 3부. AI 이미지 생성용 프롬프트

## 3-1. 사용법
1. **스타일 앵커**(공통 문장)를 모든 프롬프트 앞에 붙인다. 인물마다 그림체가 달라지는 것을 막는다.
2. 처음엔 **캐릭터 시트**(정면·측면·후면)로 생성해 모습을 확정한다.
3. 3D 변환용으로는 **단독 정면 이미지**(아래 3-4)를 따로 만든다. 3D 변환 도구는 한 장, 정면, 단색 배경, 팔을 살짝 벌린 자세에서 결과가 가장 좋다.
4. 마음에 드는 결과가 나오면 그 이미지를 **참조 이미지**로 넣어 다음 생성의 일관성을 유지한다.
5. 상업적으로 쓸 계획이면 사용하는 서비스의 상업 이용 약관을 반드시 확인한다.

## 3-2. 스타일 앵커 (모든 프롬프트 앞에)
```
chibi miniature figurine, 2.5 heads tall, big round head, simple vertical oval dot eyes, no nose, no mouth,
mitten-like rounded hands, soft matte clay and resin material, rounded beveled edges, handcrafted diorama toy,
soft diffused studio lighting, muted cool grey-blue palette with warm apricot accents, clean pastel tones,
```
**제외(네거티브):** `realistic, photorealistic, anime, sharp edges, glossy plastic, detailed fingers, text, watermark, extra limbs`
